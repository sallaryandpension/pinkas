# פנקס: ניהול חשבונות וקבלות לעוסק פטור

תוכנה לשימוש עצמי בלבד. עוסק פטור, נותן שירותים (תוספת י"א להוראות ניהול פנקסים).
התכנון המלא: `..\ניהול חשבונות וקבלות\תכנון_התוכנה.md`. בסיס הידע: `..\ניהול חשבונות וקבלות\ידע_מרוכז_ניהול_חשבונות_וקבלות.md`.

## דרישות
- Node.js 24 ומעלה. Node מריץ TypeScript ישירות, ומשתמש ב-SQLite המובנה (`node:sqlite`).

## הפעלה
לחיצה כפולה על **`הפעל פנקס.cmd`**, או `npm start`. הממשק נפתח בכתובת http://localhost:5174 ופועל במחשב הזה בלבד.
- קובצי ה-PDF נוצרים דרך Microsoft Edge המותקן.
- עותק של כל "מקור" שהופק נשמר ב-`data/outputs/`.

## הרצת הבדיקות
```
npm test
```

## מבנה
| קובץ | תפקיד |
|---|---|
| `src/db/schema.sql` | הסכמה ו-triggers שאוכפים את "הקובץ הקבוע": אין מחיקה, אין עריכה, מספור עוקב, מקור פעם אחת |
| `src/db/open.ts` | פתיחת המסד (WAL, synchronous=FULL) וטרנזקציות |
| `src/core/documents.ts` | הפקה, ולידציה, מקור/העתק, ביטול, זיכוי |
| `src/core/reports.ts` | דוח רציפות + אימות hash, כרטסת לקוח, יתרות לסוף שנה |
| `src/core/audit.ts` | יומן אירועים append-only, משורשר ב-hash |
| `src/core/expenses.ts` | הוצאות: append-only, מספור עוקב, רישום נגדי, קובץ מצורף לפי hash |
| `src/core/books.ts` | ספר תקבולים ותשלומים (הוראה 12), סיכום שנתי, מחזור מול תקרת עוסק פטור |
| `src/core/backup.ts` | גיבוי רבעוני/יומי, אימות, פלט מהגיבוי |
| `src/core/params.ts` | פרמטרים מתוארכים (210 ₪, חוק המזומן, תקרת עוסק פטור) |

## נתונים וגיבוי
- המסד נשמר ב-`data/` (לא נכנס ל-git).
- **גיבוי רבעוני (הוראה 25(ו)(2)):** במסך "גיבוי" בוחרים תיקייה על כונן חיצוני ולוחצים "גבה עכשיו". את הגיבוי עושים בשבוע הראשון של כל רבעון, ושומרים את הכונן **במקום אחר** (מחוץ לבית), **בישראל**. גיבוי לאותו כונן שבו נמצאים הנתונים נחסם. לוח הבקרה מתריע כשהגיבוי הרבעוני לא בוצע.
- **גיבוי יומי אוטומטי** ל-`data/backups/` (14 אחרונים). הוא מגן מפני תקלות, אבל לא מחליף את הגיבוי החיצוני.
- כל גיבוי הוא תיקייה `pinkas-backup-<תאריך>` שמכילה את `pinkas.db`, את `outputs/` ואת `manifest.json` עם hash לכל קובץ. הגיבוי מאומת מיד אחרי שהוא נוצר.
- **בדיקת שחזור:** במסך "גיבוי" יש לכל גיבוי שני כפתורים. "בדוק" מוודא שהקבצים, המסד והרצף תקינים. "דוח מהגיבוי" מפיק יומן רשומות ישירות מהגיבוי (25(ו)(3)).
- 🔸 יש להודיע לפקיד השומה בכתב היכן נשמרים מערכת החשבונות והגיבוי.

### שחזור מלא (רק במקרה של אובדן נתונים)
1. סגור את חלון פנקס.
2. העבר את התיקייה `data` הקיימת לשם אחר. **אל תמחק אותה.**
3. צור תיקייה `data` חדשה, והעתק לתוכה מהגיבוי את `pinkas.db` ואת התיקייה `outputs`.
4. הפעל את פנקס. במסך "דוחות" בדוק שהרצף תקין, ושהמסמך האחרון הוא אכן האחרון שהפקת.
5. ⚠️ מסמכים שהופקו **אחרי** תאריך הגיבוי לא יופיעו. צריך להשלים אותם ידנית ולתעד את האירוע.
